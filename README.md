# ootmp

A movie player, currently CLI and just a proof of concept built on bengine as base.

## Aim

The aim for this program was to get an idea of how to use ffmpeg to read video files manually for a custom renderer. This is an implementation in my openGL renderer. Will make a better and more comprehensive one once I get on vulkan.

## Features:

- Ability to read common video files with audio playback
- Implementation of shaders on the video output (4 shaders currently)

## Controls:

- Pressing F11 fullscreens(bit buggy)
- Pressing O cycles through the Shaders
